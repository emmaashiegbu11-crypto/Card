# 📇 Accessible Card Component

A delightful, highly accessible, and interactive Card deletion-and-restoration demo.

## ♿ Accessibility First
- **Keyboard Shortcuts:** Delete `(Del)`, Undo `(Esc)`, and Restore `(R)`.
- **Timer Control:** Hovering or focusing on the toast pauses the countdown.
- **Screen Readers:** Complete focus management and live announcements.
