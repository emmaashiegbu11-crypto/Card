# 📇 Accessible Card Component

A delightful, highly-accessible card component with fluid interactions, precise keyboard navigation, and an interactive demolition and recovery sandbox.

## ♿ Accessibility First

- **WCAG 2.2 compliant:** Features immediate action toast dismissal and timer pausing on hover/focus.
- **Robust Focus Management:** Restores focus gracefully and prevents keyboard focus loss or traps.
- **Visual Parity:** Paired spatial `:hover` transitions with `:focus-within` styling.
- **Tactile feedback:** Active hover and tactile button presses offer visual cues to the user.
